# Contributing

Use a focused branch and PR. Preserve the MIT license, public exports, static
fallback, keyboard behavior, motion preferences, and teardown contract. Keep
all sample data fictional and document asset provenance.

Run `npm ci`, `npm run check`, `npm run test:browser`, `npm run pack:library`,
and `npm run verify:consumers`. Include actual results and browser scope. Add
regressions for behavior changes; do not add automatic GitHub Actions workloads.
Update documentation and previews when behavior or appearance changes.
